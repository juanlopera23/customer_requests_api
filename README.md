# Customer Requests API

A simple REST API built with FastAPI to create, list, retrieve, and delete customer requests.

This project was created to learn the fundamentals of APIs, HTTP, FastAPI, Pydantic, request validation, and HTTP status codes.

## Features

- Create customer requests
- List all customer requests
- Retrieve a request by ID
- Delete a request by ID
- Automatic ID generation
- Request validation with Pydantic
- Email validation
- HTTP error handling
- Interactive API documentation with Swagger UI

## Technologies

- Python
- FastAPI
- Uvicorn
- Pydantic
